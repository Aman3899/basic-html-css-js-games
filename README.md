# 🎮 Basic HTML, CSS, JS Games

Welcome to the **Basic HTML, CSS, JS Games** repository!  
This project is a collection of small and fun web-based games built using only **HTML**, **CSS**, and **Vanilla JavaScript** — perfect for beginners and web enthusiasts who want to understand core web technologies by building interactive projects.

> 🔗 Live URL: [https://aman3899.github.io/basic-html-css-js-games/](https://aman3899.github.io/basic-html-css-js-games/) | Might be Unavailable

## 💡 Purpose

These mini-games serve as:

- 🔰 Practice for front-end fundamentals (DOM, events, logic).
- 🧠 Logic-building projects for beginner web developers.
- 🕹️ Lightweight web games to play and enjoy anytime.
- 💼 Showcase projects for portfolios or GitHub profiles.
